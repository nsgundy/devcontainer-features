# 1password-desktop 0.2.0

- Preserve the container's XDG_RUNTIME_DIR instead of globally overriding it.
- Mount only the host's canonical desktop socket.
- Enable official CLI desktop integration without setup-time settings mutation.
- Reject incompatible UID/runtime layouts and unsafe ownership or permissions.

Requires native Linux, local rootful Docker without UID remapping, Debian/Ubuntu,
a matching desktop/container UID, and the host CLI's numeric GID.

Validated across Debian 12/13 and Ubuntu 22.04/24.04, with desktop sign-in in
Dockerfile and Compose fixtures. No vault items were read.

Known limitations: desktop app restart may require container recreation; unlocked
projects may gain an empty client-generated lockfile. Cache expiry and end-to-end
secret retrieval are untested. This is experimental and not vendor-supported
container integration.
