# 1password-desktop 0.2.1

- Remove the optional diagnostic command from the Feature payload and repository.
- Keep CLI ownership, permissions, executable selection, lifecycle and runtime
  safety checks in automated tests rather than shipping a troubleshooting tool.
- Add one release workflow that validates a new version, runs the test matrix,
  publishes the Feature and collection index, verifies the public artifact, and
  creates its matching GitHub tag and Release.

The runtime/authentication implementation is unchanged from 0.2.0. Compatibility
requirements and known limitations are unchanged. Existing installations must be
rebuilt with 0.2.1 to get the smaller payload; 0.2.0 remains immutable.
